# Лабораторная работа №2: движок слабейшего предусловия (wp)

Визуальный калькулятор для вычисления слабейшего предусловия по методу Хоара. Приложение позволяет анализировать фрагменты кода (присваивания, последовательности, ветвления) и автоматически выводить необходимые начальные условия для гарантированного достижения заданного постусловия.

Разработано на **C#** с использованием **WPF** (.NET 8).

---

## Возможности приложения

*   **Парсинг кода**: поддержка операторов присваивания (`=`, `:=`), последовательностей (`;`) и условных операторов (`if-else`).
*   **Математические выражения**: поддержка `+`, `-`, `*`, `/`, `>`, `<`, `>=`, `<=`, `==`, `!=`, `&&`, `||`, `!`, `abs()`, `sqrt()`
*   **Пошаговый трейс**: визуализация того, как постусловие "тянется" с конца к началу через каждый оператор.
*   **Двойной вывод результата**: итоговое предусловие отображается как в краткой математической записи, так и "человеческим языком".
*   **Условия определённости**: автоматический вывод ограничений (например, `знаменатель != 0` при делении).
*   **Триада Хоара**: генерация и отображение финальной формулы `{Pre} P {Post}`.
*   **Встроенные пресеты**: готовые сценарии из ТЗ для быстрой демонстрации.

---

## Как пользоваться

1. Запустите приложение и перейдите на вкладку **«Конструктор фрагмента»**.
2. В поле **«Цель (Post)»** введите желаемое условие после выполнения кода (например, `x > 15`).
3. В поле **«Код фрагмента»** введите программу или выберите один из **пресетов** в выпадающем списке.
4. Нажмите кнопку **«Рассчитать wp»**.
5. Изучите **пошаговый трейс** в нижней части окна, чтобы понять логику преобразований.
6. Ознакомьтесь с итоговым предусловием и условиями определённости (выделены красным, если есть риски, например, деления на ноль).
7. Нажмите кнопку **«Показать триаду»**, чтобы увидеть итоговое доказательство корректности в формате `{Pre} P {Post}`.

## Встроенные пресеты

| Название | Код фрагмента | Постусловие (Post) | Ожидаемый результат (wp) |
| :--- | :--- | :--- | :--- |
| **Max из двух** | `if (x1 >= x2) { max = x1 } else { max = x2 }` | `max > 100` | `(x1 >= x2 && x1 > 100) \|\| (x1 < x2 && x2 > 100)` |
| **Последовательность** | `x = x + 10; y = x + 1` | `(y == x - 9) && (x > 15)` | `x > 5` |
| **Квадратное ур-е** | `if (D >= 0) { root = (-b + sqrt(D)) / (2 * a) } else { root = -1 }` | `(D >= 0 && a*root*root + b*root + c == 0) \|\| (D < 0 && root == -1)` | Условия корректности + `a != 0` |

## Архитектура решения

Проект разделен на логические слои:
1. **View-Model**: связывает классы с интерфейсом, выполняет парсинг входящих данных.
2. **Engine**: реализует математические правила обратной предикатной трансформации (подстановка `Exchange`, обратный проход по `Sequence`, дизъюнкция для `if`).
3. **Expressions**: реализует перевод в математический вид и перевод на **Человеческий язык**.
4. **Statement**: работает с последовательносятми.
5. **UI**: Код в `MainWindow.xaml.cs` связывает текстовый ввод, парсер, движок и элементы интерфейса, форматируя вывод.
